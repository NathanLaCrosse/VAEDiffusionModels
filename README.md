# Attempt at Stable Diffusion
Authors: Nathan LaCrosse, Matthew Peplinski, and Jake Swanson

## Our Project
We attempt to recreate the stable diffusion model from this [paper](https://arxiv.org/abs/2006.11239) by Cornell University.

We utilize a dataset from [Kaggle]([Mushroom species](https://www.kaggle.com/datasets/thehir0/mushroom-species)) that contains images of mushrooms. There are various different species of mushrooms. This is perfect for being able to utilize the hybridization capabilities of a diffusion model.
